# ПАУТИНА

Браузерная аркада на маятниковой физике: герой-паутинщик движется по городу,
цепляясь нитями за крыши и мачты. Гравитация — единственный настоящий противник,
земля — единственная точка невозврата.

Игра целиком написана на чистом JavaScript и Canvas 2D: без зависимостей,
без сборки, без сети.

## Как запустить

Достаточно открыть `index.html` в браузере. Скрипты подключены обычными тегами,
поэтому игра работает и с `file://`.

Если хочется локального сервера:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Прицел | мышь или палец |
| Выстрелить паутину | зажать кнопку мыши / коснуться экрана |
| Отпустить нить | отпустить кнопку |
| Раскачка и управление в воздухе | `A` / `D` (или стрелки) |
| Подтянуть / отпустить нить, лазать по стене | `W` / `S` |
| Прыжок с крыши, отталкивание от стены, авто-паутина | `Пробел` |
| Заново / пауза / звук | `R` / `P` / `M` |

## Механика

- **Маятник.** Нить — это ограничение максимальной длины, а не пружина. Радиальная
  скорость гасится в момент натяжения, тангенциальная сохраняется, поэтому
  подтягивание нити в нижней точке дуги разгоняет героя за счёт сохранения
  момента импульса.
- **Зацеп.** Выстрел трассируется лучом по городу. Попадание в фасад соскальзывает
  к краю крыши и повисает чуть в стороне от угла, чтобы дуга качания оставалась
  вне стены. Цепляться можно только выше собственной головы.
- **Стены не убивают.** Удар о фасад гасит нормальную составляющую скорости и
  оставляет героя висеть на стене. Убивает только асфальт.
- **Отталкивание.** На стене герой держится сам: пока он висит, физика поддавливает
  его к фасаду, иначе обнуление горизонтальной скорости тут же разрывало бы контакт.
  Оттолкнуться можно `Пробелом` или кликом мыши, и есть окно 0.22 с после касания —
  можно оттолкнуться, уже отлетев от стены. Направление зависит от того, что зажато:
  - ничего — прыжок под 45° в сторону от стены;
  - клавиша **от** стены — низкий и быстрый рывок вдоль неё;
  - клавиша **в** стену — почти вертикальный толчок, чтобы подниматься по колодцу;
  - клик мышью — толчок точно в сторону прицела, но никогда назад в стену.

  Часть скорости, с которой герой пришёл в стену, добавляется к толчку, поэтому
  быстрый заход выгоднее вялого. Отталкивание работает и когда герой висит на
  паутине и одновременно прижат к фасаду — раньше это было тупиковой позой.
- **Крыши.** На них можно приземляться, бегать и прыгать — это способ восстановить
  темп после неудачной дуги.
- **Комбо.** Энергосферы в пролётах между домами поднимают множитель; он сгорает,
  если не подбирать их дольше пяти секунд.

## За что можно цепляться

Помимо крыш и фасадов город оснащён отдельными объектами для зацепа. Часть из них
твёрдая — на неё можно приземлиться, часть ловит только паутину, и герой сквозь
неё пролетает.

| Объект | Где встречается | Твёрдый | Зачем |
| --- | --- | --- | --- |
| Мачта на крыше | почти на каждом высоком доме | нет | базовый высокий якорь |
| Строительный кран | около 28% домов | стрела — да, ствол — нет | вылет стрелы даёт точку прямо над пролётом |
| Трос между домами | больше половины пролётов шире 150 px | нет | якорь в середине пустоты, когда герой проседает вниз |
| Билборд на крыше | около 30% домов без крана | да | низкая точка у самого края крыши, на неё можно сесть |
| Дирижабль | раз в 2800–4800 px, на высоте 1180–1750 | нет | единственный якорь выше линии крыш; медленно дрейфует, и паутина едет вместе с ним |

Генератор дополнительно гарантирует, что мачта высотой не меньше 760 px над улицей
встречается не реже чем раз в 700 px по горизонтали.

## Темп игры

Общая скорость регулируется одной константой `PACE` в начале `src/util.js`.
Скорости масштабируются как `PACE`, ускорения — как `PACE²`, поэтому форма всех
траекторий сохраняется, меняется только время их прохождения: дуги качания,
высота прыжков и дальность нити остаются прежними.

- `PACE = 1` — исходный, быстрый темп;
- `PACE = 0.7` — текущее значение, примерно на треть спокойнее;
- меньше `0.5` — уже похоже на лунную гравитацию.

## Разработка

```bash
node tools/sim.js 60         # headless-прогон 8 сидов с автопилотом
node tools/probe.js 1000 20  # подробная трасса одного забега
node tools/wall-test.js      # проверка прилипания к стене и всех видов толчка
node tools/smoke.js          # загрузка в headless Chrome, ошибки консоли, толчок
node tools/shots.js          # проход камерой по городу со скриншотами
```

Симуляция загружает боевой код физики и мира без браузера — она использовалась
для отладки маятника, зацепов и восстановления после падения.
