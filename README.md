# ПАУТИНА

Браузерная аркада на маятниковой физике: герой-паутинщик движется по городу,
цепляясь нитями за крыши и мачты. Гравитация — единственный настоящий противник,
земля — единственная точка невозврата.

Игра целиком написана на чистом JavaScript и Canvas 2D: без зависимостей,
без сборки, без сети.

## Как запустить

Достаточно открыть `index.html` в браузере. Скрипты подключены обычными тегами,
поэтому игра работает и с `file://`.

Если хочется локального сервера:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Прицел | мышь или палец |
| Выстрелить паутину | зажать кнопку мыши / коснуться экрана |
| Отпустить нить | отпустить кнопку |
| Раскачка и управление в воздухе | `A` / `D` (или стрелки) |
| Подтянуть / отпустить нить, лазать по стене | `W` / `S` |
| Прыжок с крыши, отталкивание от стены, авто-паутина | `Пробел` |
| Заново / пауза / звук | `R` / `P` / `M` |

## Механика

- **Маятник.** Нить — это ограничение максимальной длины, а не пружина. Радиальная
  скорость гасится в момент натяжения, тангенциальная сохраняется, поэтому
  подтягивание нити в нижней точке дуги разгоняет героя за счёт сохранения
  момента импульса.
- **Зацеп.** Выстрел трассируется лучом по городу. Попадание в фасад соскальзывает
  к краю крыши и повисает чуть в стороне от угла, чтобы дуга качания оставалась
  вне стены. Цепляться можно только выше собственной головы.
- **Стены не убивают.** Удар о фасад гасит нормальную составляющую скорости и
  оставляет героя висеть на стене: оттуда можно лезть вверх (`W`) и оттолкнуться
  (`Пробел`). Убивает только асфальт.
- **Крыши.** На них можно приземляться, бегать и прыгать — это способ восстановить
  темп после неудачной дуги.
- **Комбо.** Энергосферы в пролётах между домами поднимают множитель; он сгорает,
  если не подбирать их дольше пяти секунд.

## Разработка

```bash
node tools/sim.js 60     # headless-прогон 8 сидов с автопилотом
node tools/probe.js 1000 20  # подробная трасса одного забега
```

Симуляция загружает боевой код физики и мира без браузера — она использовалась
для отладки маятника, зацепов и восстановления после падения.
